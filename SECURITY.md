# Security policy

Please report a vulnerability privately through GitHub. Open the repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue for it.

Reports are especially useful for:
- a secret value reaching a lockfile or the output;
- a file outside the project being read;
- any network access, or anything being launched or executed;
- a change that `verify` reports as Unchanged.

This is an alpha maintained by a small team, so there is no response-time guarantee. Fixes ship in a new release, and
the changelog credits the reporter if they want that.

Supported version: the latest release only.
